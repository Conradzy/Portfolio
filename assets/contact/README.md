# Contact icons

Transparent PNG cutouts prepared with the built-in imagegen tool from the user's `github.png`, `gmaill.png`, `facebook.png`, and `linkedin.png` images. The originals were preserved.

Outputs: `github.png`, `gmail.png`, `facebook.png`, `linkedin.png` in this directory.

Prompt used for each icon (substituting its filename for `{name}`):

> Use case: background-extraction. Edit target: the attached {name} social app icon. Remove only the surrounding white background and floor shadow, leaving true transparent alpha outside the rounded-square 3D icon. Preserve the entire original glossy icon, exact logo, colors, internal white surfaces, lighting, proportions and perspective. No redesign, no added text, no background, no border. Keep the complete icon centered with a small transparent margin. This is a website contact icon.
