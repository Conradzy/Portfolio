# Tech Stack keyboard assets

- Reference image: supplied by the portfolio owner. Used only as a loading/WebGL fallback.
- Procedural keycap/chassis model and animations: created for this portfolio in keyboard-scene.js.
- Brand SVGs except the three noted below: https://github.com/devicons/devicon (MIT; see DEVICON-LICENSE). Original variants except Django's plain variant.
- Cisco and phpMyAdmin SVGs: https://github.com/simple-icons/simple-icons (CC0; see SIMPLE-ICONS-LICENSE.md). Monochrome silhouettes tinted for readability at runtime.
- WampServer SVG: https://uxwing.com/wampserver-icon/ and https://uxwing.com/wp-content/themes/uxwing/download/brands-and-social-media/wampserver-icon.svg (see https://uxwing.com/license/).
- RoundedBoxGeometry: Three.js r184; vendored under assets/vendor/three/geometries, covered by assets/vendor/three/LICENSE.

Brand marks belong to their respective owners. Django, WampServer, Arduino, Vercel, Cisco, and phpMyAdmin are tinted on the canvas key labels to match the reference and retain contrast; their SVG source files are preserved.
